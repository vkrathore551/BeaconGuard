# BeaconGuard — The Last Beacon

An interactive emergency survival and safe-route planning dashboard built with Python and Streamlit.

## Features
- Interactive 10×10 survival map
- Zombie and obstacle simulation
- Safe-route planning
- Hazard-aware navigation
- Interactive dashboard

## Technologies
- Python
- Streamlit
- Git and GitHub

## How to Run

Install Streamlit:

```bash
pip install streamlit
```

Start the application:

```bash
streamlit run ui.py
```

## Project Purpose
Developed as a hackathon project to demonstrate emergency survival simulation and route planning.

**Note:** This is a simulation prototype, not a real emergency-response system.
